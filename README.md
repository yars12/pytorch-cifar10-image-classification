# PyTorch CIFAR-10 Image Classification

A deep learning computer-vision project built with **PyTorch** to classify images from the **CIFAR-10** dataset.

The project includes a custom convolutional neural network, an optional ResNet-18 model, data augmentation, reproducible training, learning-rate scheduling, early stopping, checkpointing, test-set evaluation, confusion-matrix visualization, and training curves.

## Project Highlights

- Trains on the 10-class CIFAR-10 image dataset
- Uses image augmentation for stronger generalization
- Supports two model choices:
  - Custom CNN
  - ResNet-18 adapted for 32×32 CIFAR-10 images
- Uses AdamW optimization and cosine learning-rate scheduling
- Tracks training and validation loss and accuracy
- Saves the best model checkpoint automatically
- Evaluates the final model on the held-out test set
- Produces `metrics.json`, `training_curves.png`, `confusion_matrix.png`, and `best_model.pt`
- Includes reproducibility controls through a fixed random seed

## Dataset

**CIFAR-10** contains 60,000 color images across 10 classes:

`airplane`, `automobile`, `bird`, `cat`, `deer`, `dog`, `frog`, `horse`, `ship`, `truck`

The dataset is downloaded automatically through `torchvision`.

## Model Architecture

### Custom CNN

The custom model uses convolutional feature blocks, batch normalization, ReLU activations, max pooling, dropout, global average pooling, and a fully connected classification head.

### ResNet-18

The project can also train a ResNet-18 model adapted for CIFAR-10 by replacing the original large-image input stem with a smaller 3×3 convolution and removing the initial max-pooling layer.

## Training Strategy

- Optimizer: AdamW
- Loss: Cross-entropy with label smoothing
- Scheduler: Cosine annealing
- Validation split: 10% of the original CIFAR-10 training set
- Early stopping based on validation loss
- Best-checkpoint restoration before test evaluation

## Run the Project

Install dependencies:

```bash
pip install -r requirements.txt
```

Train the custom CNN:

```bash
python train.py --model cnn --epochs 20
```

Train ResNet-18:

```bash
python train.py --model resnet18 --epochs 20
```

For a quicker test run:

```bash
python train.py --model cnn --epochs 2
```

## Output

After training, the script creates an `artifacts/` folder containing the best checkpoint, evaluation metrics, training curves, and confusion matrix.

## Results

Performance metrics are generated by the training script and written to `artifacts/metrics.json`.

This repository does **not** claim a benchmark score until the model has been trained in a completed run. This keeps the documented results tied to actual model output.
